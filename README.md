# 铁幕前线 · Iron Front

横屏单人即时战略 iOS App。启动进入遭遇战大厅，从九个国家中选择玩家国家，选择一张内置地图，再给 0–7 个电脑席位分别选择国家。所有图片、战场规则和声音随应用安装，可离线游玩。

## 运行

用 Xcode 打开 [IronFront.xcodeproj](IronFront.xcodeproj)，选择 **IronFront** scheme 和一台 iPhone 模拟器，按 ⌘R。连接自己的 iPhone 时，在 **Signing & Capabilities → Team** 中选择开发团队，选中设备后运行。部署目标为 iOS 16.0，支持横屏 iPhone 和 iPad。

[构建好的 iPhone arm64 Release App](Products/iPhoneOS/IronFront.app) 使用未签名设备构建。通过 Xcode 安装到真机时会使用所选团队签名。

## 功能与规则

| 模块 | 本版实现 |
| --- | --- |
| 对战设置 | 每张地图支持 1–8 个参战席位。仅留玩家席位即可进入自由演练，对战时可加入 1–7 个独立电脑。支持逐席选国、三档难度、三档资金和战争迷雾开关。 |
| 基地建设 | 基地车可移动、展开。建造厂解锁电厂、矿场、兵营、战车工厂、雷达及作战实验室。建筑生产完成后选择地块，预览占地并确认放置。建造范围、地形、矿区和已有建筑都会影响选址。 |
| 经济与供电 | 建成精炼厂随附一辆矿车。盟军超时空矿车和苏军武装采矿车会自动寻找可到达的矿石、采集、卸矿并再次出发。盟军可跃迁返厂，苏军走陆路。每片矿田中央的中立矿井持续补充普通金矿。缺电会拖慢生产，关闭雷达及耗电防御。维修消耗资金，变卖按剩余耐久退款。 |
| 作战 | 25 种建筑、31 种机动单位，分属盟军和苏军。步兵、战车、空军、舰船使用不同移动和攻击规则，支持攻击目标、进攻移动、自动交战、射程、冷却、范围效果及空地目标限制。 |
| 国家特色 | 美国空降伞兵，英国狙击手，法国巨炮，德国坦克杀手，韩国黑鹰，苏俄磁暴坦克，古巴爆破手，伊拉克辐射工兵，利比亚自爆卡车。 |
| 特殊交互 | 工程师可占领敌方建筑或修复己方建筑，美国大兵可部署，维修厂能修理附近车辆。海岸地图可沿水边建船坞。天气控制器和导弹发射井充能后可呼叫范围打击。 |
| 电脑对手 | 每国独立管理资金、矿车、科技树和部队。电脑可以同时生产不同型号，按难度组织进攻，并与其他电脑互相交战。开启迷雾时，部队沿出生方位搜索，只有获得视野才能锁定目标和使用支援。 |
| 胜负与存档 | 失去全部建筑和基地车的国家被淘汰。有对手的遭遇战在玩家成为最后存活方时结算胜利。自由演练可持续建设，保存后可继续，也可从暂停菜单主动结束。运行中每 15 个游戏秒自动保存，切入后台会暂停并保存，也可从暂停菜单保存退出。 |

## 第一局

1. 点大厅左下角的地图选择战场，设置自己的国家和电脑席位。电脑为 0 时点 **开始演练**，有对手时点 **开始对战**。点 **展开基地** 会打开底部生产栏。上排切换类别，下排可横滑选建筑或单位。点发电厂开始建造，点向下箭头可收起生产栏。
2. 点单位图标或左下角 **＋** 立即订购，右上角 `×N` 是该型号待产数，包含正在生产的一件。不同型号同时生产，同型号逐件完成。深色遮罩从 12 点方向顺时针揭开，资金随进度扣除。余额用完时图标显示 **待资金** 和已完成百分比，矿车交款等收入到账后自动续建。点 **−** 优先撤掉最后追加的一件，长按图标可以直接取消当前一件。取消只退已付金额。例如一名造价 500 的工程师在已付 250 时取消，会退回 250。建筑完成后点对应图标选址，再点 **确认放置**。未放置的建筑只会让下一座同型号建筑等待，其他型号继续建造。
3. 建成矿石精炼厂后，随厂矿车会自动开始采集。每个出生点附近和中央矿区各有一口矿井。每隔 3 秒，每口矿井向周围可用地块最多补入 180 单位普通金矿。采空后仍会再生，中央的原生宝石采完后让位给金矿。矿石运回精炼厂才会增加资金。建兵营解锁步兵，矿场和兵营就绪后可建战车工厂。
4. 点己方单位，再点地面移动或点敌方攻击。点 **进攻** 后指定地面会沿途交战。拖动能平移，双指缩放，双击选中附近同型单位。左下角有基地定位、框选和全军。点选中单位的铭牌，可记录或召回编队，也可维修、变卖建筑或部署步兵。
5. 点右上角的雷达表盘展开小地图。供电正常且拥有雷达建筑时，可在图上点击或拖动定位，轮廓表示当前镜头范围。左上角可暂停、保存退出和查看操作说明。

## 数据与美术

项目从 [L3 单位参数 JSON](https://www.l3.pub/units_data.json) 中提取所用条目的价格、耐久、电力、速度、视野、装甲和原始前置字符串。站点数据集标注为《尤里的复仇》。本版从中筛选原版九国适用的条目，记录保留在 [roster.json](Sources/FrontCore/Resources/roster.json)。数据库缺少双方展开后的建造厂独立记录，两个建造厂沿用对应基地车的造价和耐久，文件的 `sourceId` 标出来源。雷达站、多功能步兵车等易混淆条目按单位 ID 校正显示名，并保留原始名称。

生产栏使用网络取得的 54 张原版生产图标，两个工程师以及两个建造厂分别共享图标。可按 [数据导入脚本](Tools/import_roster.py) 中的 ID 和文件名追溯。图标来自 CNCNZ 的[盟军单位](https://cncnz.com/games/red-alert-2/allied-units/)、[盟军建筑](https://cncnz.com/games/red-alert-2/allied-structures/)、[苏军单位](https://cncnz.com/games/red-alert-2/soviet-units/)和[苏军建筑](https://cncnz.com/games/red-alert-2/soviet-structures/)图录，对应原作由 Westwood Studios / Electronic Arts 制作发行。

战场使用以原图为参考、通过内置 ImageGen 重建的透明等距精灵。装甲、航空和舰船使用前后视图与左右镜像，步兵搭配转向和行进起伏。建筑、单位、矿石和树木的独立 PNG 位于 [Art/Sprites](IronFront/Art/Sprites)，原版参考图标位于 [Art/Cameos](IronFront/Art/Cameos)。[大厅插画](IronFront/Art/frontline.jpg)及完整[美术提示词](Tools/art-direction-brief.txt)也保存在项目中。短音效由 [make_audio.py](Tools/make_audio.py) 合成。

中立矿井参考 FinalAlert 2 的 **Ore Mine** 地形物及原作矿田截图。战场使用独立重建的高清[矿井贴图](IronFront/Art/Sprites/ore-drill.png)。刷新间隔、产量与覆盖范围采用本作的遭遇战参数。[FinalAlert 2 矿区制图说明](https://forums.cncnet.org/topic/8245-how-to-make-ra2-yr-maps-final-alert-2-tutorial/?comment=78962&do=findComment) · [原作实机参考图](https://images.steamusercontent.com/ugc/2474238502428869138/4B12286A1BCD619A8A9273306007B3E1195CEBFE/)

部署台、雷达、生产栏和战报共用一张用 ImageGen 生成的[野战设备金属纹理](IronFront/Art/field-steel.jpg)。装甲边缘、信号灯、选区准星和实时雷达由原生界面绘制，使用同一套美术提示词文件记录底纹的制作方式。

本版为重新实现的遭遇战规则。生产节奏、伤害、射程、冷却、寻路、镜头比例和 AI 为触屏对战设计。原作完整兵种、逐帧动画、载具乘员组合与老兵升级属于尚未覆盖的内容。

## 工程与验证

大厅与生产面板使用 SwiftUI，战场使用 SpriteKit，手势使用 UIKit，音效使用 AVFAudio。模拟规则位于 [Sources/FrontCore](Sources/FrontCore)，固定步长为 1/8 秒，渲染独立插值。Xcode 工程直接包含核心源文件和本地资源，首次运行无需安装第三方依赖。

[核心规则测试](Tests/FrontCoreTests/SkirmishTests.swift) 可在项目根目录用 `swift test -c release` 运行。测试覆盖十张地图和 1–8 席的全部 80 种组合、三张海战图的 24 个出舰位置、自由演练存读档、不同型号并行、同型号串行、资金耗尽停工与矿车交款续建、按实际支出退款、小额收入在型号间轮转、多个就绪建筑任选部署、全额预付旧存档恢复，矿井持续再生、矿车可达路径、旧地图迁移，以及作战和完整对局。

在 Xcode 选择 iPhone 模拟器后按 ⌘U 运行[界面测试](IronFrontUITests/SkirmishUITests.swift)。测试操作真实的大厅和战场，覆盖十图选择、单人演练与八席开局、部署基地、放置建筑、生产、查看矿井、矿车连续自动交款、退出和重启读档，以及选择七个电脑后由实际战斗触发结算。
